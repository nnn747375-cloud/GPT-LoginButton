# Security policy

This repository contains a WinForms control and a demo that starts the local,
community-maintained `openai-oauth` bridge. It must be kept on loopback and
must never expose ChatGPT credentials to the network.

Do not open an issue containing API keys, OAuth codes, access tokens, refresh
tokens, cookies, `auth.json`, browser profiles, account identifiers or private
chat content. Remove the secret and report the problem privately through a
GitHub security advisory.

The repository should contain source and release binaries only. Local auth
files and generated user data do not belong in commits.
